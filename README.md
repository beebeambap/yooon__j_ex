# Instagram 캐러셀 템플릿 (2026.06 · 260410 반영)

표지·내지·영상 장을 입력하면 **배경 투명 PNG 레이어**(텍스트 + 하단 스크림)를
장별로 내려받는 단일 페이지 웹 도구입니다. 추출한 PNG를 사진 위에 얹어 사용합니다.

## 빠른 시작
별도 빌드·설치가 없습니다. `index.html`을 브라우저로 열면 됩니다.
(로컬 서버 권장: `python3 -m http.server` → `http://localhost:8000`)

## 입력 항목
| 장 | 입력 |
|---|---|
| **표지** | 날짜(YYMMDD, 자유 편집) · 주제(타이틀) · 부제 |
| **내지** | 본문 내용 (페이지 인덱스 자동) |
| **영상/인덱스** | (선택) "사진에 텍스트 있음 → 렌더 안 함" 체크 |

## 출력 (현재 / 전체 × 2종)
- **투명 PNG** — 텍스트+스크림만, 배경 투명 (사진 위에 얹는 레이어용)
- **합성 JPG** — 업로드한 배경 사진 + 텍스트를 한 장으로 구운 불투명 이미지
  (사진 미선택 시 `#FAFAFA` 베이스). 1080×1350, 품질 0.92
- 파일명은 **표지 날짜가 맨 앞**: `260614_carousel_01_cover.jpg`, `260614_carousel_02_body.png` …
- 안전마진 가이드는 미리보기 전용으로, 출력 이미지에는 포함되지 않습니다.

## 배경 사진 합성
- 각 장 편집 패널에서 **배경 사진(선택)** 업로드 → 미리보기에 합성된 모습으로 표시
- 사진은 캔버스에 cover-fit으로 배치되고 그 위에 텍스트가 얹힙니다
- 사진은 브라우저 메모리에서만 처리(서버 업로드 없음) · 용량 문제로 새로고침 시 재선택

### 표지(01)
- 스크림: 화면 55%부터, 투명도 0→205, 곡선 1.3
- 날짜: 우상단(우측 끝 = 마진), y≈78, 옅은 그림자
- 흰 키커 룰: 타이틀 위, 70×3, 타이틀 상단 30px 위
- 타이틀: 좌하단, x = 마진−4, 부제 바 위 24px
- 부제 바: 슬레이트 라운드(반경 8), 안 여백 좌우26·상하16, 바닥 = H−64
- 표지엔 인덱스 미표기

### 내지(02…N)
- 블록 하단 정렬, 바닥 = H−78
- 인덱스 `NN / NN`(슬레이트) — N = 표지 포함 총 장수
- 슬레이트 룰: 인덱스 오른쪽 18px, 60×4
- 본문: 인덱스 아래 62px부터, 흰색, 행간 70, 줄바꿈 폭 936px
- 스크림: 본문 블록 상단 −90px부터, 투명도 205

### 영상 / 인덱스-온리
- 스크림: H−180부터, 투명도 190
- 인덱스만(y≈H−120) + 슬레이트 룰, 본문 없음
- 사진에 텍스트 박혀 있으면 렌더 안 함(체크박스)

### 텍스트 원칙
- 원문 단어 불변경 — 줄바꿈·배치만
- 맞춤법 교정은 요청 시만(단어·의미 유지)
- 엔딩 텍스트는 슬라이드가 아닌 '캡션'에 별도 작성

## 파일 구조
- `index.html` — 레이아웃 (미리보기 / 입력 패널)
- `styles.css` — 다크 UI, 투명 미리보기 체크무늬
- `app.js` — `SPEC` 상수 + Canvas 렌더 엔진 + 에디터 + PNG 출력

## 폰트 교체 (Freesentation TTF 확보 시)
1. `index.html`의 Google Fonts `<link>` 제거
2. `styles.css` 상단에 `@font-face`로 Freesentation TTF 등록
3. `app.js`의 `SPEC.FONT` 값을 `'"Freesentation", sans-serif'`로 변경
